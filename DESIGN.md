# DocForge: Dusk workspace

Direction supplied by the user: the Dusk theme at https://www.usehallmark.com/themes/dusk/, the anti-slop reference at https://github.com/miqdadbadjuber/anti-slop, and the supplied silver-blue cat illustrations.

## Visual direction

An Indonesian document workspace with the quiet atmosphere of dusk. Charcoal and blue-grey surfaces, warm off-white text, periwinkle actions, and a restrained amber accent. Dark surfaces surround the actual white document, making the output the visual focus. Noto is served locally for legible Indonesian forms; headings use the same family with a larger, lighter weight. Monospace is reserved for code and JSON.

## Composition

Horizontal navigation for the two real destinations. A short introduction, compact document choices, then a wide form beside a sticky preview. Optional template/field settings live in an explicit disclosure. Mobile uses one column and full-size controls. The PDF converter shares navigation, type scale, surfaces, and spacing.

## Mascot

Use the user's silver-blue tabby, amber eyes and pearl necklace. The mascot appears in the introduction and empty states. It does not cover controls or replace status messages. Source illustration belongs to the user; the production cutout is generated from that reference. No stock portraits, fake reviews, fictional usage counts, gradient text, or decorative badge clusters.

## Interaction and validation

Keep every document-generation, custom-field, background-upload, batch and conversion flow. Keep clear upload errors next to their inputs, visible keyboard focus, text descriptions for status, and reduced-motion support. Output stays ephemeral. No remote fonts, tracking or new account flows.

## Logo

Use the user-provided document-and-hammer reference, reconstructed as a vector mark. The fragmented document and hammer use periwinkle (#b5bafa), with an off-white docforge wordmark on the dark navigation. Keep the mark flat and unboxed. The same mark is the favicon.
