1. File mana yang ditempel?

Salin TemplateDokumen.ts ke folder template proyekmu. File ini sudah berisi fungsi, tipe data, HTML, CSS, dan gambar latar. Kamu tidak perlu memasang package DocForge, Handlebars, pdf-lib, atau menyertakan PDF asal untuk memakai fungsi ini.

Satu file template sudah cukup. Impor dan panggil dari file aplikasi yang sudah ada, misalnya komponen, service, atau handler tombol. File pemanggil tambahan seperti preview.ts hanya untuk merapikan struktur; tidak wajib membuat aplikasi baru atau memakai semua file ZIP.

Contoh frontend TypeScript: sediakan <div id="preview"></div> pada halaman, lalu gunakan kode ini:

Impor template, kirim data, tampilkan HTML

Ganti data contoh dengan data form, API, atau sumber data aplikasimu. Untuk React/Vue, panggil fungsi template dari komponen dan tampilkan hasilnya pada iframe melalui srcDoc/srcdoc. Sesuaikan path impor dengan proyekmu; contoh memakai ekstensi .js untuk resolusi modul Node/TypeScript.

2. Library apa yang dipakai di proyekmu?

Kebutuhan Yang dipakai Input
Menampilkan desain sebagai HTML Fungsi template + iframe, tanpa package PDF Data → HTML
Membuat file PDF Renderer HTML-ke-PDF, contoh Playwright di Node.js/server HTML → PDF
Preview PDF di browser pdfjs-dist (PDF.js) Byte PDF → canvas

Kalau proyekmu sudah memakai PDF.js: hasil fungsi template perlu dijadikan PDF oleh renderer dahulu. PDF.js menerima PDF yang sudah jadi, bukan string HTML. 

Template(data) → HTML → renderer PDF → byte PDF → PDF.js → canvas

Jika proyek sudah memiliki renderer HTML-ke-PDF, gunakan renderer tersebut. Playwright di bawah hanya salah satu contoh integrasi.

3. Contoh membuat PDF dengan Playwright

Pasang dependensi yang belum tersedia pada proyek Node.js milikmu. Tidak perlu menjalankan init atau membuat proyek baru.

npm 
npm install playwright
npm install --save-dev tsx
npx playwright install chromium
npx tsx example.ts
pnpm 
pnpm add playwright
pnpm add -D tsx
pnpm exec playwright install chromium
pnpm exec tsx example.ts

Playwright menjalankan Chromium untuk mencetak HTML menjadi PDF. tsx hanya diperlukan untuk menjalankan contoh TypeScript langsung; jika proyek sudah punya build/runner, gunakan yang sudah ada. node:fs/promises adalah modul bawaan Node.js. Contoh membutuhkan Node.js 22.13+. Pada Linux/server, dependensi Chromium dapat dipasang dengan npx playwright install --with-deps chromium.

example.ts: panggil template yang sudah ditempel

Contoh ZIP membuat hasil.html dan hasil.pdf agar mudah dicoba. Dalam backend aplikasi, kamu bisa mengambil Buffer dari page.pdf() dan mengirimnya sebagai respons application/pdf tanpa menyimpan file. Playwright dijalankan di server/Node.js, bukan langsung dalam komponen frontend.

4. Menampilkan PDF dengan PDF.js

Pasang library pada frontend: npm install pdfjs-dist atau pnpm add pdfjs-dist. Contoh berikut khusus proyek TypeScript dengan Vite, yang mendukung impor worker ?url. Untuk bundler lain, sesuaikan konfigurasi worker dan pastikan versinya sama dengan library.

Fungsi ini menerima byte PDF dari renderer/server aplikasimu dan elemen canvas yang sudah ada. Contoh menampilkan halaman pertama. Tidak ada proses membaca PDF asal untuk dikonversi ulang.

preview-pdf.ts (frontend Vite)

Setelah kode aplikasi menerima byte PDF, panggil tampilkanPdf(pdfBytes, canvasElement). Pengambilan byte dari API mengikuti alur aplikasi yang sudah kamu punya. Ganti getPage(1) bila ingin menampilkan halaman lain.

File ZIP lain dan catatan integrasi

example.ts adalah contoh pemanggil. template.html, schema.json, sample-data.json, dan config.json merupakan jalur alternatif bagi renderer yang memakai format template DocForge. File-file tersebut tidak perlu diimpor jika kamu memakai fungsi template TypeScript.

Tanggal memakai string YYYY-MM-DD. Validasi data eksternal tetap dilakukan oleh aplikasi pemanggil. Periksa font, posisi, dan teks panjang. Tabel berulang, pagination isi dinamis, dan logika aplikasi perlu disesuaikan di kode proyekmu.

Dokumentasi: PDF.js dan Playwright.

Paket ZIP berisi fungsi .ts, template.html, schema.json, sample-data.json, config.json, dan contoh penggunaan. Layout hasil konversi mengikuti halaman PDF; ukuran teks dan font mungkin perlu penyesuaian.
