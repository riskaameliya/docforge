Taruh font berlisensi .ttf/.woff2 di sini. HTML: `@font-face { font-family: MyFont; src: url('/fonts/MyFont.ttf'); }`.

Overlay menggunakan nama file TTF di properti `font`. NotoSans-Regular.ttf disertakan dengan lisensi SIL Open Font License (OFL.txt), dan dipakai contoh surat/sertifikat. Font bawaan default tanpa konfigurasi adalah Helvetica. Pilih font yang memiliki glyph untuk karakter data Anda.
